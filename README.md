# Marine Litter Monitor

An interactive dashboard visualizing marine litter monitoring data collected
by **Científicos de la Basura**, a citizen science program coordinated by
ESMOI (Universidad Católica del Norte) operating across 10 Latin American
countries.

## What it does

- Displays georeferenced beach sampling data on an interactive map
- Shows litter composition by type (plastics, cigarette butts, glass, metals,
  and more) per beach and per country
- Lets users filter and compare sampling events across locations and dates
- Breaks down data by transect and station for detailed site-level analysis

## Tech stack

- **Leaflet.js** — interactive mapping
- **Chart.js** — data visualization and charts
- **noUiSlider** — range filtering controls
- Vanilla HTML/JS, no build step — data is embedded directly in the page

## Data source

Sampling data was collected by volunteers, schools, universities, and
conservation organizations participating in the Científicos de la Basura
program. Data covers dozens of beaches across Chile, Peru, Ecuador,
Colombia, Panama, Costa Rica, Guatemala, El Salvador, Mexico, and
Nicaragua.

## About this project

Built as a freelance data visualization contract for Científicos de la
Basura (ESMOI / Universidad Católica del Norte), February–May 2026.
